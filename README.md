# 💼 Search Work – Cartelera de Postulaciones Laborales

Proyecto desarrollado para el Obligatorio de Programación 1 de la carrera Analista en Tecnologías de la Información – ORT Uruguay.

## 📖 Descripción

Search Work es una aplicación web que permite gestionar una cartelera de ofertas laborales con dos perfiles de usuario:

* Postulantes, que pueden registrarse, iniciar sesión y postularse a ofertas laborales.
* Administradores, que gestionan ofertas, procesan postulaciones y visualizan estadísticas del sistema.

El proyecto fue desarrollado utilizando únicamente las tecnologías y conceptos trabajados durante el curso.

## 🚀 Funcionalidades

### 👤 Postulante

* Registro de usuarios.
* Inicio y cierre de sesión.
* Visualización de ofertas compatibles.
* Filtro por área de interés.
* Postulación a ofertas laborales.
* Consulta de postulaciones realizadas.
* Catálogo de ofertas destacadas.

### 🛠️ Administrador

* Inicio y cierre de sesión.
* Crear ofertas laborales.
* Editar ofertas existentes.
* Cierre lógico de ofertas.
* Procesamiento de postulaciones.
* Estadísticas generales del sistema.
* Búsqueda de ofertas por título.

## 📊 Estadísticas

El sistema incluye:

* Cantidad de postulaciones por oferta.
* Total de ofertas activas, inactivas y cerradas.
* Porcentaje de vacantes cubiertas.
* Postulante con mayor cantidad de postulaciones activas.
